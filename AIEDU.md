# aiEDU — Get Educated with AI (Ai_Education portal)

Embedded module: **`ai-education.html`** (and `ai-education/index.html`) — opened by the
**"Get Educated with AI"** tile on the home page, the `aiEDU Portal` tag in the all-rooms
strip, and the footer Resources list.

Source document preserved verbatim in `store/ai-education.html`. The embed strips the
module's top utility bar, sticky nav and footer (the Ai Metaverse shell provides chrome),
scopes its CSS under `.ed-embed`, and inlines the Tailwind CDN runtime with the module's
`edu` color palette (`corePlugins:{preflight:false}`).

## How to Use This

- **Save the file:** Copy the code and save it as `ai-education.html`.
- **Open in Browser:** Double-click to view the fully responsive, modern educational
  platform interface.

## Key Features Included

- **Role-Based Learning Paths:** Clean cards for Students, Educators, and Professionals.
- **3-Month Strategic Framework:** A visually appealing stepped layout for the learning
  phases.
- **Video Reference Block:** A styled placeholder for the Ali Abdaal YouTube guide.
- **aiEDU Mission & News:** Dedicated sections for the 501(c)(3) mission, news articles,
  and partner logos.
- **Newsletter Signup:** A functional-looking form with a success alert.
- **Constellation25 Aesthetic:** Maintains the sleek, dark-mode, glassmorphic design with
  cyan/purple gradients, ensuring it feels like a premium, cutting-edge tech education hub.
