Core Components of a Creator Toolkit

Whether you are using Spatial, Viverse, or Meta Horizon Worlds, creator toolkits combine the power of a standard 3D game engine with specific cloud-hosted multiplayer features.

3D Scene Editor

Integrated via Unity Editor or dedicated desktop tools. Lay out 3D models, paint terrain, bake lighting, and configure collision physics.

Interactivity & Scripting

Visual scripting or standardized languages (TypeScript, C#) to build complex game logic, trigger actions, and handle player events.

Asset Pipelines

Built-in tools for importing industry-standard 3D formats (FBX, OBJ). Optimize custom assets from Blender or Maya for real-time performance.

Avatar & Networking

Automatic handling of multiplayer matchmaking, real-time voice/text communication, and customizable avatar systems out of the box.

Step-by-Step Workflow

A typical setup using a package like the Spatial.io Creator Toolkit follows these sequential milestones.

01

Setting Up

Initialize the developer environment.

  • Create an account on the target platform (e.g., Spatial.io).
  • Install the designated engine version via Unity Hub.
  • Download and import the platform's official Starter Template SDK.
02

Importing Assets

Bring in the visual elements of your environment.

  • Gather 3D geometry in FBX or OBJ formats.
  • Rig custom humanoid avatars using Mixamo or AccuRig.
  • Organize files into dedicated asset subfolders in your hierarchy.
03

Designing the Logic

Make the virtual space interactive.

  • Define spatial components like spawn points, teleport pads, and seating.
  • Attach script behaviors to game objects (e.g., opening hyperlinks).
  • Configure lights, reflections, and audio settings to optimize performance.
04

Testing & Publishing

Deploy the experience live to your community.

  • Use built-in mobile/web simulation previews to test multiplayer sync.
  • Build and publish directly through the toolkit's configuration window.
  • Share the resulting cross-platform URL for instant VR/PC/mobile access.
