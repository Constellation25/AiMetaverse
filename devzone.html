Bridge a real terminal

This shell is in-page. To drive a real terminal — Termux on a phone, or any user shell over ssh — pair it with the Python backend:

pip install -r py/requirements.txt python py/main.py --no-window # phone (Termux): same one-liner, then # http://<phone-ip>:8080 # any box: ssh -R 8080:localhost:8080 you@host

When window.eel appears, the companion and this terminal flip to bridge mode automatically (bridge to check).
