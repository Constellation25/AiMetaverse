Privacy first. The recording is held in memory as a temporary blob URL so you can play it back. Only the derived numbers (pitch, loudness, pace, character) are saved to localStorage. Close the tab and the audio is gone. No voice model is trained or uploaded in this build.
Need real voice cloning? Wire py/main.py to a TTS provider that accepts a reference sample (ElevenLabs, Coqui, OpenAI TTS) — the recorded blob is already exposed through the Eel bridge.

How the traits are computed. Zodiac base scores are modified by element (Fire +courage, Earth +calm, Air +wit, Water +empathy), then by your birth day, birth month and life-path number, and clamped to 6–99. Deterministic: the same birthday always produces the same agent personality.
For entertainment. Astrology is a personality flavour, not a psychometric instrument. Edit any trait by hand in the agent spec before you deploy.

What happens to your data

  • Selfie is downscaled to ≤560 px and kept as a data URL in localStorage.
  • Audio is never written to storage — only pitch, loudness, pace and character.
  • Birthday is stored as yyyy-mm-dd plus the traits derived from it.
  • Zero network calls except Google Fonts and the optional Ready Player Me frame.
  • “Delete everything” wipes the storage key instantly and irreversibly.
